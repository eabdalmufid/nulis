# ✍️ Bot Nulis

Generator tulisan tangan digital — ketik teks kamu, pilih font, dan download hasilnya dalam hitungan detik.

## 🚀 Demo

**[eabdalmufid.github.io/nulis](https://eabdalmufid.github.io/nulis)**

![screencapture](https://user-images.githubusercontent.com/76531998/204364654-5eb9982d-2573-43c4-9033-7d615de18c98.png)

## ⚡ Fitur

- **4 Pilihan Font** — Tersedia 4 font tulisan tangan yang berbeda (HandwritingCR-2, Gloria Hallelujah, Heart Warming, Shadows Into Light)
- **Live Preview** — Lihat hasil tulisan secara langsung sebelum di-download
- **Download PNG** — Simpan hasil tulisan dalam format gambar PNG
- **Mobile Friendly** — Bisa digunakan di HP, tablet, maupun komputer

## 📖 Cara Pakai

1. **Pilih Font** — Pilih salah satu dari 4 font tulisan tangan yang tersedia
2. **Isi Data** — Masukkan hari/tanggal, nama, dan isi materi
3. **Lihat Preview** — Cek hasil tulisan di live preview
4. **Download** — Klik tombol *Download PNG* dan simpan hasilnya

## 🛠️ Teknologi

- HTML, CSS, JavaScript
- [p5.js](https://p5js.org/) — canvas rendering
- [Bootstrap 4](https://getbootstrap.com/)
- [jQuery](https://jquery.com/)
